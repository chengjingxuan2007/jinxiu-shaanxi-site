========================================
        锦绣陕西 · 网站使用教程
        （给完全不懂技术的朋友看）
========================================

这份说明不讲技术名词，只讲三件事：
  1. 怎么把这个网站打开看
  2. 每个文件是干什么的
  3. 想改内容的话，要装什么软件、改哪里

除了地图底图需要联网，其余内容都是本地文件；
不需要装环境、不需要花钱。


────────────────────────────────────
一、最快的上手方式：3 秒钟打开网站
────────────────────────────────────

1. 打开这个文件夹「锦绣陕西2026.10.24」

2. 找到文件：index.html

3. 在它上面【双击】

   正常情况下，它会自动用电脑上的浏览器打开，
   你看到的就是这个网站的首页。

   推荐用 Chrome 或 Edge 浏览器打开（兼容性最好）。
   360、QQ 浏览器也可以，偶尔会有小瑕疵。

4. 如果双击以后，出来的是一堆看不懂的代码，
   或者用「记事本」打开了：

   在 index.html 上点【右键】→【打开方式】→【选择其他应用】
   → 选 Chrome 或 Edge（任意浏览器即可） → 勾上「始终用此应用打开」
   → 确定。

   这样以后双击就都是浏览器打开了。

5. 打开之后，页面顶部有菜单栏，
   鼠标移到菜单名字上会弹出下拉菜单，
   点里面任意一条就能直接跳到那个内容。

   右上角有：
     · 放大镜图标 —— 全站搜索
     ·「EN / 中」按钮 —— 中英文一键切换

────────────────────────────────────
三、五个文件夹，分别装什么
────────────────────────────────────

【image 文件夹】—— 装所有图片
  网站上的照片、海报、缩略图，全都在这里（.jpg 格式）。
  想换图片：把新图片改成跟原来一样的文件名，直接覆盖就行，
  不用动代码。

【video 文件夹】—— 装所有视频
  首页背景视频、AI 漫剧、形象片、几道菜的做法视频（.mp4 格式）。
  同样，想换视频就同名替换。

【css 文件夹】—— 管「好不好看」
  颜色、字体、字号、间距、排版、动画效果，都写在里面。
  改一个颜色，整个网站的按钮、标题颜色就跟着变。
  文件说明：
    common.css —— 全站通用（导航栏、页脚、地图、抽屉、配色）
    scenic.css —— 只管风景页
    culture.css —— 只管民俗页
    food.css —— 只管美食页

【js 文件夹】—— 管「能不能动」
  点击、弹出、切换中英文、地图展开这些动作，都写在里面。
  其中最重要的一个：

  ★ data.js —— 整个网站的「内容仓库」★

  所有景点介绍、手艺来历、菜品说明、城市资料、时间轴年份，
  全部集中在这一个文件里。
  想改错别字、改介绍文字、加一条新内容，改它就行，
  不用去翻网页文件。

【vendor 文件夹】—— 装地图引擎（OpenLayers）
  三个页面和首页用的真实地图，靠它渲染。
  里面是现成的库文件，一般不用动；
  想换地图底图，改 js/map.js 最上面的 token（见第八节）。


────────────────────────────────────
四、想改内容，要装什么软件？
────────────────────────────────────

先说一句大实话：
  网页不需要「编译」，不像 Java、C 语言那样要装大型编译环境。
  你只要用「能写字的软件」把文件改了、保存，
  回浏览器刷新一下，效果立刻就出来了。

所以严格来说，Windows 自带的【记事本】就能改。
但记事本看代码很难受（没有颜色、没有行号），
建议装下面这些编辑器（都免费）：

★★★ 首选：VS Code（强烈推荐，全世界的网页开发者都在用）
  下载地址：https://code.visualstudio.com
  安装时一路点「下一步」即可。
  装好后第一次打开，它会提示安装中文语言包，点「安装」，
  界面就变成中文了。
  用它打开文件夹：文件 → 打开文件夹 → 选「锦绣陕西2026.10.24」，
  左边会出现整个文件树，点哪个改哪个，很直观。
  必装插件（左侧方块图标里搜名字，点安装）：
    · Chinese (Simplified)  —— 中文界面
    · Live Server           —— 改完自动刷新页面（推荐）
    · Prettier              —— 一键把代码排版整齐

★★ 次选：HBuilderX（国产、纯中文、上手更简单）
  下载地址：https://www.dcloud.io/hbuilderx.html
  专门做网页用的，界面全是中文，对新手更友好。

★  备用：Notepad++（很小巧，装了就能用）
  下载地址：https://notepad-plus-plus.org

临时改一行字、手边没软件时：
  右键文件 → 打开方式 → 记事本，也能改，改完保存即可。


────────────────────────────────────
五、改完以后怎么看效果？
────────────────────────────────────

方法 A（最简单）：
  1. 保存文件（Ctrl + S）
  2. 回到浏览器
  3. 按 F5 刷新
  4. 如果刷新后还是老样子，按 Ctrl + F5 强制刷新
     （浏览器有时会偷懒用缓存，Ctrl+F5 能解决 90% 的「改了没反应」）

方法 B（装了 Live Server 插件）：
  在 VS Code 里对着 index.html 点右键 →「Open with Live Server」
  它会自己开一个网页，以后你每按一次保存，网页自动刷新，
  不用手动按 F5。

六、常见问题（照着做基本都能解决）
────────────────────────────────────

Q：双击 html 文件，出来一堆代码？
A：右键 → 打开方式 → 选 Chrome / Edge。

Q：我明明改了，网页上却没变？
A：先确认文件保存了（Ctrl+S），再按 Ctrl + F5 强制刷新。

Q：图片变成裂开的小图标（不显示）？
A：多半是文件名对不上。检查 image 文件夹里有没有这张图，
   名字是否一模一样（包括 .jpg 后缀、中英文、大小写）。

Q：视频不播放 / 没声音？
A：浏览器规定：视频不能自动带声音播放，
   需要点一下页面任意位置，或者点视频右下角的播放按钮。
   这是浏览器规则，不是网站坏了。

Q：中英文切换点了没反应？
A：刷新一下页面。切换状态是记住的，下次打开还是上次选的语言。

Q：想把网站发给别人看？
A：把整个「锦绣陕西2026.10.24」文件夹压缩成 .zip 发出去。
   对方解压后，双击 index.html 就能看。
   注意：一定要整个文件夹一起发，只发一个 html 文件会缺图少样式。

Q：想放到网上，让别人用网址访问？
A：那就需要买域名 + 服务器（或虚拟主机），把整个文件夹传上去。
   也可以先用 GitHub Pages（免费）练手。
   这一步涉及备案和费用，需要的话再单独说。

八、真实地图：怎么换成天地图官方底图
────────────────────────────────────

首页的「城市缩影」和风景 / 民俗 / 美食三个页面的地图，
现在都是 OpenLayers 渲染的真实地图，光点位置按真实经纬度标注。

没有密钥时，底图会自动使用备用路网图，页面不会空白。
想换成天地图官方底图，只要两步：

1. 打开 https://console.tianditu.gov.cn/api/key
   免费注册后申请一个「浏览器端」密钥（一串字母数字，叫 tk）。

2. 用编辑器打开 js/map.js，最上面有几行设置：
     token: '',
     layer: 'img',
   把密钥填进引号里：
     token: '你申请到的那串字符',
   保存、刷新网页即可。
   地图左下角的「© 高德地图 · 备用底图」会自动变成「© 天地图」。

补充：
  · layer 可填 'img'（卫星影像）、'vec'（矢量路网）、'ter'（地形）。
  · 城市光点在真实地图上按经纬度定位，数据来自 js/data.js 里每个城市的 coord。
  · 点开某处景点 / 非遗 / 美食时，地图会自动飞到它的位置并标出红色定位点；
    关闭右侧面板，地图自动回到全省视野。条目位置在 data.js 的 D.geo 里维护。
  · 地图框左上角外侧是「＋ / －」缩放按钮，右下角外侧是方向盘（↑ ← ↓ →）；
    屏幕变窄时会自动贴到地图框内侧。
  · 地图瓦片来自网络，所以看地图时要联网；其余内容仍是纯本地文件。

九、最后啰嗦两句
────────────────────────────────────

1. 改代码前，先复制一份整个文件夹当备份。
   改坏了还能退回来，这一步能救很多次。

2. 这个网站是「静态网站」：
   没有数据库、不需要后台、不用装运行环境，
   双击就能看，拷到 U 盘里换台电脑也能看。

3. 遇到报错别慌，99% 的情况是：
   文件名写错了 / 少了个引号或括号 / 没保存 / 浏览器缓存。
   按上面的顺序排查一遍基本都能解决。
